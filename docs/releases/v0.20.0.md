# v0.20.0

## 新增

- 新增“静默 OCR”：截图识别后直接将文字复制到剪贴板，并显示复制提示；可在设置中录制专用快捷键。([#99](https://github.com/cosZone/MoePeek/pull/99))
- Google 翻译支持可选的 HTTP CONNECT 代理配置与连接测试；代理默认关闭，仅作用于 Google 翻译，连接失败时不会绕过已配置的代理。([#109](https://github.com/cosZone/MoePeek/pull/109))
- 新增 Requesty 翻译服务，支持配置 API Key、获取模型列表及使用 OpenAI 兼容模型。([#100](https://github.com/cosZone/MoePeek/pull/100))

## 修复

- 修复 Bing 返回额外元数据时，解析失败并丢失正常翻译结果的问题。([#110](https://github.com/cosZone/MoePeek/pull/110))
- 修复静默 OCR 与智能取词的剪贴板恢复操作竞争，导致识别结果被覆盖的问题；取消或过期的 OCR 操作不会再写入剪贴板。
- 调整 OpenAI 兼容服务的连接测试 token 上限，避免 Requesty 对部分 OpenAI 模型误报连接失败。
- 打开设置时主动将窗口置于前台，改善快捷键录制无法接收键盘输入的问题。([#99](https://github.com/cosZone/MoePeek/pull/99))

**Full Changelog**: https://github.com/cosZone/MoePeek/compare/v0.19.2...v0.20.0
