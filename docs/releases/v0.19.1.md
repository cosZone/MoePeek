# v0.19.1

## 体验改善与修复

- 翻译结果较长时，浮窗会随内容增长，并限制在屏幕可见范围内；超出的内容仍可滚动。短结果保持原有高度。([#104](https://github.com/cosZone/MoePeek/pull/104))
- 修复简体与繁体中文互译时，自动识别源语言后可能将目标语言错误切换为英文的问题；源语言与目标语言为同一字形时，仍按原有规则自动切换。([#103](https://github.com/cosZone/MoePeek/pull/103))
